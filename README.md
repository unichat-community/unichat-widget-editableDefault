# UniChat Widget - editableDefault

[🇺🇸 English](./README.md) | [🇧🇷 Português](./README.pt-br.md)

This widget is the same [**UniChat**](https://codeberg.org/unichat/unichat)'s `default` widget, but with the ability to edit its source code and with editable fields in the **UniChat** editor.
